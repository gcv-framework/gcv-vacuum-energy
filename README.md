# Gauged Constant Vacuum-Mode Cosmology (GCV)

## One-sentence summary

GCV is a flux-fixed GR framework in which the strictly spacetime-constant vacuum zero mode is excluded from retained local stress, ordinary local excitations remain in the local stress-energy tensor, and independent compact/flux data label the geometric branch.

## Current scientific status - 27 July 2026

Read [CURRENT_STATUS.md](CURRENT_STATUS.md) before using the route map. The accepted RAPS Source-Assignment paper is the current conditional local source-split theorem. The [provenance-typed source-law preprint](https://doi.org/10.5281/zenodo.21590693) proposes a stronger fixed-physical-branch no-transfer law under explicit closure hypotheses.

Governance-UV v1.2.0 / CFI Section 6.2 is superseded as the proposed radiative-stability foundation and downstream response anchor. The presently established late-time landing is GR+`Lambda_eff`, without an additional derived growth, lensing, or transient response. Historical records and priority timestamps are preserved.

## Core GCV priority claim

The core GCV priority claim is a source-assignment criterion for the exact spacetime-constant vacuum zero mode: under explicit admissibility conditions, it is excluded from the retained local gravitational source, while ordinary local excitations gravitate normally.

Local matter, radiation, fields, curvature-dependent terms, shells, semiclassical stress, perturbations, and other local excitations remain in the local stress tensor and gravitate normally. The source-assignment claim concerns only the exact spacetime-constant vacuum zero mode.

## Core local equation

```text
G_{μν} + Λ_eff g_{μν} = 8πG T^loc_{μν}
```

Here `T^loc` contains local excitations but excludes strictly spacetime-constant vacuum contributions. `Λ_eff = Λ_eff(K_phys)` is the geometric branch output of independent compact/flux data. Moving this term across the equation does not turn it into matter.

## Historical role of the Governance Bridge

The Governance Bridge records the earlier source-assignment architecture and translates the IR GR-exact target into UV-facing admissibility language. It does not establish the stricter fixed-physical-branch no-transfer result proposed in the July 2026 provenance-typed source law.

It assigns sources before solving:

- exact spacetime-constant vacuum zero mode → excluded from retained local stress;
- independent compact/flux datum → geometric branch label;
- local excitations → local stress-energy;
- candidate UV-side realizations → tested against the source-assignment law;
- lawful crossing → GR-exact landed branch;
- bounded transient and perturbation-sector effects → historical or conditional downstream test layers requiring their own occurrence/source theorem;
- unsafe leakage of constant vacuum back into local gravity → red-line failure.
